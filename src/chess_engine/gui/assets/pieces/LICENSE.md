# Chess pieces

The twelve SVG files are the *cburnett* set by [Colin M.L. Burnett](https://en.wikipedia.org/wiki/User:Cburnett),
taken from the [Lichess repository](https://github.com/lichess-org/lila/tree/master/public/piece/cburnett)
(`public/piece/cburnett`, 2026-10-30), which lists them under the
[GPLv2+](https://www.gnu.org/licenses/gpl-2.0.txt). Naming: colour (`w`/`b`) plus piece letter (`K Q R B N P`).
